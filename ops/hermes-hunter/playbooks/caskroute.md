# План охоты - CaskRoute (агент обновляет сам после каждой охоты)
## 1. Источники и запросы
- STORES (первыми): независимые liquor stores и малые сети 5-10 магазинов по городу: карты (OpenStreetMap), реестры лицензий TABC (TX) и аналоги штатов, сайты магазинов (нет ли публичного API/онлайн-каталога), отзывы; запросы «liquor store <city>», «<city> wine and spirits chain».
- Сообщества покупателей 21+: Reddit (r/bourbon, r/tequila, r/whiskey, городские), Facebook-группы, клубы дегустаций, локальные блогеры-обзорщики. Магазины - не клиенты.
## 2. Веса оценки
- Поправки: пока нет.
## 3. Карта территории
- Texas: Houston, Dallas, Austin, San Antonio; Colorado: Denver; Arizona: Phoenix, Tucson; Florida: Miami, Tampa, Orlando - все следующие.
## 4. Типы целей: STORES малые сети 5-10 -> независимые магазины -> сообщества покупателей -> блогеры -> клубы.
