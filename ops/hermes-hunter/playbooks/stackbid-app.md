# План охоты - StackBid App (агент обновляет сам после каждой охоты)
## 1. Источники и запросы
- CONTRACTORS: сайты handyman/малых подрядчиков, Thumbtack/Yelp/BBB публичные страницы, реестры лицензий штата; запросы «handyman <city>», «small remodeling contractor <city>».
- HOMEOWNERS: открытые сообщества ремонта по городу (форумы, Reddit r/<city>, группы).
## 2. Веса оценки
- Урок 14.10: лучшие цели - owner-operated handyman с широким набором работ и публичным email/phone.
## 3. Карта территории
- Phoenix AZ (пройден 14.10, CONTRACTORS), Mesa, Tucson, Dallas, Houston, Austin, San Antonio, Denver, Las Vegas, Atlanta, Tampa, Orlando - следующие.
## 4. Типы целей: HOMEOWNERS сообщества (первыми, сервис для домовладельцев) -> CONTRACTORS.
